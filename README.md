# Hospital-Management-Dashboard-PowerBI
Interactive Hospital Management Dashboard built in Power BI to analyze patient care, revenue, clinical performance, operational efficiency, and business insights using DAX, Power Query, and data modeling.

📌 Project Overview

This Power BI dashboard provides a comprehensive analysis of hospital operations, patient care, financial performance, and clinical insights. It enables healthcare stakeholders to monitor KPIs, explore patient records, analyze treatment costs, and identify strategic opportunities for improving operational efficiency.

🎯 Objectives

Monitor hospital performance using KPI cards
Analyze clinical trends and treatment costs
Explore patient-level hospital records
Provide actionable business recommendations
Enable interactive filtering through slicers
